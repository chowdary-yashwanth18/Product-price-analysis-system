Technologies Used

  • Python — main programming language Python 3.13 core backend & data pipelines
  • Requests — fetch web pages where appropriate Session management & custom header spoofing in scripts/scraper_requests_bs4.py
  • BeautifulSoup — parse HTML CSS selector querying & structured schema extraction
  • Selenium — handle dynamically rendered pages Headless Chrome automation & JS scrolling in scripts/scraper_selenium.py
py scripts/scraper_requests_bs4.py
📊

Analytics Stack

  • Pandas — data cleaning and analysis Deduplication, type coercion, grouping & arbitrage calculation
  • NumPy — numerical operations Vectorized offsets, price differences & spread metrics
  • Matplotlib / Seaborn — visualization 16 high-resolution charts in scripts/generate_seaborn_charts.py
  • CSV / SQLite / MySQL — storage Relational database in data/database/products.db & CSV exports
  • Streamlit — optional interactive dashboard Multi-page interactive application in streamlit_app.py
py -m streamlit run streamlit_app.py

LG 55" OLED TV Price Swing

The same LG 55-inch OLED TV fluctuates from ₹1,08,000 on the cheapest website to ₹1,24,080 on the most expensive. That's a ₹16,080 price difference (14.9%) for the exact identical unit!

🏆 DISCOUNT CHAMPION

Flipkart Leads in Discounts

With an average discount of 14.07% and average selling price of ₹46,175, Flipkart consistently undercuts Croma (12.18%) and Vijay Sales (12.16%) across comparable categories.

Average savings: ₹6,432 per transaction
📈 CATEGORY ECONOMICS

Televisions Deliver Highest Savings

While Smart TVs hold the highest ticket prices (Average ₹75,260), they also provide the absolute largest monetary savings (Up to ₹18,489 below MRP per unit). Conversely, mice and earbuds offer micro-discounts under ₹1,500.
